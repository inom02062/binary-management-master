Заявка на участие в конкурсе «Лобачевский Прорыв»

Направление: Информационные технологии.
Тема: Разработка комплексной автоматизированной системы визуального управления жилищным фондом и мониторинга финансовых потоков «Binary Learn Management».
Инструменты: Язык программирования JavaScript/TypeScript, среда выполнения Node.js, фреймворк React 19, СУБД SQLite, ORM Prisma.

Раздел: Введение.
Сфера управления коммерческой и жилой недвижимостью в современных городских агломерациях сталкивается с проблемой «информационного хаоса». Традиционные методы учета — бумажные журналы или электронные таблицы — теряют эффективность при масштабировании объектов. Отсутствие визуальной привязки данных к физическому расположению квартир и сложность оперативного контроля за дебиторской задолженностью приводят к финансовым потерям. Моя идея заключается в создании интерактивной платформы, объединяющей в себе графический редактор карт застройки и интеллектуальную систему финансового планирования. Проект направлен на создание «цифрового двойника» жилого комплекса, где администратор может в режиме реального времени видеть статус каждого юнита и управлять потоками платежей.

Раздел: Система управления базами данных.
В проекте используется реляционная СУБД SQLite в связке с объектно-реляционным отображением (ORM) Prisma.
    • Обоснование выбора: SQLite обеспечивает высокую скорость работы при локальном развертывании и не требует сложного администрирования сервера. Prisma позволяет гарантировать строгую типизацию данных и безопасность запросов.
    • Структура БД: База данных спроектирована по иерархическому принципу:
        1. Таблица «Блоки» (хранение координат, размеров и параметров зданий).
        2. Таблица «Квартиры» (статус объекта, данные арендатора, связь с блоком).
        3. Таблица «Платежи» (история транзакций, даты и статусы оплат).
Это позволяет выполнять сложные аналитические запросы, например, моментальный расчет задолженности по конкретному этажу или всему зданию.

Раздел: Программные библиотеки и инструменты.
Для реализации системы выбраны современные инструменты, обеспечивающие максимальный UX (User Experience):
    • React 19 & Vite: Обеспечивают мгновенный отклик интерфейса и быструю сборку приложения.
    • Lucide React: Библиотека компонентов для визуализации инструментов управления (иконки, навигация).
    • Tailwind CSS: Используется для создания адаптивного дизайна с поддержкой темного режима, что снижает нагрузку на зрение оператора при длительной работе.
    • Docker: Обеспечивает контейнеризацию проекта, гарантируя одинаковую работу системы на любом устройстве (Windows, Linux, macOS).

Раздел: Логика работы визуально-аналитического ядра.
Ключевая особенность системы — интеграция графической визуализации с бизнес-логикой. Процесс работы делится на три ключевых этапа:

1. Визуальное моделирование (Map Engine)
    • Координатная привязка: Каждое здание в системе является объектом с динамическими координатами (X, Y) и размерами.
    • Реактивное управление: При изменении размеров здания в редакторе, система автоматически пересчитывает масштаб и пропорции, сохраняя точность отображения на всех устройствах.

2. Состояние системы и Offline-синхронизация
Для обеспечения непрерывности работы внедрен механизм синхронизации:
    • Очередь отложенных операций (Pending Ops): Если интернет-соединение прерывается, все действия администратора сохраняются в локальное хранилище (LocalStorage) в виде очереди.
    • Фоновая проверка (Health Check): Программа каждые 5-10 секунд проверяет доступность сервера. Как только связь восстанавливается, очередь «сбрасывается» на сервер, обеспечивая целостность данных без потери информации.

3. Алгоритм управления задолженностью и рассрочкой
Система не просто фиксирует оплату, а анализирует финансовое состояние юнита:
    • Статус объекта: Автоматическое присвоение статусов (Свободно, Оплачено, Долг) на основе даты последнего платежа.
    • Генератор рассрочки: При вводе крупной суммы система предлагает алгоритм деления платежа на равные части по месяцам, автоматически создавая график будущих транзакций.
